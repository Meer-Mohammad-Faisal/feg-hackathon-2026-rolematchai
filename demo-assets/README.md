# Demo Assets

This folder contains assets for the SessionIQ demo presentation.

## Contents

### Screenshots
- `screenshots/` - Application screenshots for presentation
  - `demo-selection.png` - Demo mode selection screen
  - `control-mode.png` - Control mode interface
  - `intelligent-mode.png` - Session Intelligence interface
  - `session-insight.png` - Session Insight panel
  - `analytics-dashboard.png` - Analytics dashboard

### Presentation
- `presentation/` - Slide deck for hackathon presentation
  - `sessioniq-presentation.pptx` - Main presentation file

### Data Samples
- `data/` - Sample data files for testing
  - `sample-content.json` - Sample content data
  - `sample-sessions.json` - Sample session data

## Usage

These assets are for demonstration purposes only. All data is fictional and not connected to production systems.

## Adding New Assets

1. Place screenshots in the `screenshots/` folder
2. Update this README with descriptions
3. Ensure file names are descriptive and follow naming conventions
